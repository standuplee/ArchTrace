# ADR 0002: 원본 보존과 합성 데이터 분리

상태: 채택.

## 결정

합성 샘플은 `bronze.synthetic_bldrgst_title`에만 적재하고 `is_synthetic=true`를 기록한다. 공식 파일 명세가 확보되기 전에는 운영 표제부 파서로 취급하지 않는다.

원본 객체는 `raw/objects/sha256/<hash>`에 저장한다. 동일 내용은 한 번만 저장하고 데이터셋·스냅샷별 manifest가 이를 참조한다. 이는 PRD의 월별 파일 경로를 내용 기반 객체와 월별 manifest로 나눈 구현이다. 파일명·크기·최초 수집시각·출처·기준월·해시를 manifest에 보존한다.

조건부 쓰기로 기존 객체와 manifest를 덮어쓰지 않는다. 재처리는 raw를 다시 읽고 해시를 검증한 뒤 진행한다. 현재 메모리 전체 읽기는 작은 합성 CSV에만 허용한다. 대용량 원본의 스트리밍 수집·압축 해제 계보는 2주차 작업이다.

bronze의 월·지역 범위를 원자적 overwrite로 교체한다. 여러 파일로 구성된 동일 월·지역은 먼저 합쳐 검증한 뒤 한 번에 교체해야 한다. 현재 명령은 **선택 지역의 완전한 단일 fixture**만 받는다. 멱등성은 조회 행의 동일성이지 Iceberg 스냅샷 ID의 동일성을 뜻하지 않는다.
