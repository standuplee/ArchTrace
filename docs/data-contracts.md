# 데이터 계약 초안

실제 HUB 파일 명세와 샘플이 없어 운영 계약은 미확정이다. 아래는 저장·조회 검증용 **합성 CSV 계약**이며 공식 컬럼 매핑이 아니다.

| 합성 CSV | Iceberg | 자료형 | 검증 |
|---|---|---|---|
| mgmBldrgstPk | mgm_bldrgst_pk | string | 비어 있지 않음, 선택한 스냅샷 내 중복 거부, 앞자리 0 유지 |
| sigunguCd | sigungu_cd | string | 설정 지역만 선택 |
| pnu | pnu | string | 19자리 ASCII 숫자, 지역 접두사 일치 |
| mainPurpsCd | main_purpose_cd | string | 원문 보존, 코드 유효성은 미검증 |
| totArea | total_area | decimal(18,4) | 유한·음수 아님·소수 4자리 이하 |
| useAprDay | approval_date | date | YYYYMMDD, 공백은 null |

적재 메타데이터: `snapshot_ym`, `source_sha256`, `raw_uri`, `manifest_uri`, `is_synthetic`.
컬럼 집합이 다르거나 선택 지역의 품질 오류가 있으면 Iceberg 쓰기 전에 실패한다. 지역 선택 결과가 0건이면 기존 파티션을 지우지 않는다.

## 실제 파일 확보 후 확정할 항목

- 데이터셋별 행 단위, 기본 키와 부모 키. 전유부 PK가 표제부 PK와 동일하다고 가정하지 않는다.
- HUB 전환 전후 PK 변환 규칙과 원본 시스템 구분.
- 지번 필드에서 PNU 생성 시 0→1, 1→2 변환 근거와 블록·결측 처리.
- 승인일·말소일의 의미 및 유효하지 않은 날짜의 격리 기준.
- 면적 단위·정밀도와 삭제·말소 사유.
- 전체 스냅샷의 완전성 확인 방법. 수집 실패를 건물 소멸로 처리하지 않는다.

## 시간과 이력 해석

데이터 기준월, 다운로드 시각, 변경 관측일, 원문 업무 발생일을 구분한다. 현재 승인일을 이용해 과거 용도나 전체 변경 이력을 복원하지 않는다. 월별 변경은 관측 구간으로 표현하며 정확한 발생일로 단정하지 않는다.
