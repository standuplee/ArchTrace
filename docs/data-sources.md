# 데이터 확보 현황

확인일: 2026-10-07. 공개 안내 확인과 실제 파일 검증을 구분한다.

## 공식 출처에서 확인한 사항

- [건축HUB 대용량 제공](https://www.hub.go.kr/portal/opn/lps/idx-lgcpt-pvsn-srvc-list.do): 월별 현황을 제공하며 안내상 제공일은 익월 20일이다. 제공년월과 데이터 기준월을 별도로 기록해야 한다. 목록의 날짜 검색은 과거 파일의 실제 다운로드 가능성을 보장하지 않는다.
- [총괄표제부 메타정보](https://www.hub.go.kr/portal/opn/tyb/idx-bdrg-totldr.do): 대지구분은 0=대지, 1=산, 2=블록. 블록은 PNU로 임의 변환하지 않는다. 이 웹 메타정보를 대용량 파일 명세와 동일하다고 가정하지 않는다.
- [건축물대장 API](https://www.data.go.kr/data/15134735/openapi.do): 기본개요·총괄표제부·표제부·층별개요·전유부 등을 제공. HUB 전환 과정에서 PK가 변경되었다는 안내가 있으므로 구·신 PK를 섞어 매칭하지 않는다.
- [건축인허가 API](https://www.data.go.kr/data/15136267/openapi.do): JSON/XML 형식, 기본개요·동별·층별·철거멸실관리대장 등 제공. 실제 응답과 연결 키는 인증 후 검증해야 한다.

## 확보 현황

| 데이터셋 | 경로 | 실제 파일/응답 | 남은 검증 |
|---|---|---|---|
| 총괄표제부 | HUB 대용량 | 미확보 | 파일 제공 단위, 기준월, PK 관계 |
| 표제부 | HUB 대용량 | 미확보 | 인코딩, 컬럼 순서, 중복 키 |
| 층별개요 | HUB 대용량 | 미확보 | 행 단위와 부모 연결 키 |
| 전유부 | HUB 대용량 | 미확보 | 호실 키와 표제부 연결 키 |
| 건축인허가 | 공공데이터포털 API | 미확보 | 인증, 페이지 방식, 대장 직접 연결 키 |
| 말소대장 | HUB 대용량 후보 | 미확보 | 정확한 서비스명, 말소 사유, 멸실 확정 가능성 |

## 사용자가 준비할 항목

1. 건축HUB 로그인 후 표제부 파일과 동봉 명세를 우선 확보한다. 가능하면 서로 다른 기준월 2개를 받는다.
2. 공공데이터포털에서 위 건축인허가 API 활용신청을 한다. 대장 API는 파일 대조용으로 선택 신청한다.
3. 발급받은 인증키는 `.env`의 `DATA_GO_KR_SERVICE_KEY`에 저장한다. 현재 샘플 명령은 API를 호출하지 않는다.
4. 원본 파일은 `data/incoming/`에 수정 없이 둔다(경로는 Git 제외). 압축 파일도 그대로 보존한다.

전국 파일이면 원본은 전국 범위를 보존하고 bronze에서 지역을 선택한다. 파일 크기·인코딩·구분자·헤더·추출일·제공월·기준월을 실제 파일로 확인한 뒤 파서를 추가한다.

활용신청 문구 예시: “마포구 건축물대장과 건축인허가 정보를 연결하여 건축물 생애주기와 변경 이력을 분석하는 개인 데이터 엔지니어링 학습 프로젝트. 로컬 환경에서 연구·분석 목적으로 활용.”
